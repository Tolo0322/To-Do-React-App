# ✅ To-Do React-App

Una aplicación de lista de tareas moderna e intuitiva construida con **React** y estilizada con **Tailwind CSS**. Perfecta para organizar tus actividades diarias con una interfaz limpia y modo oscuro.

## ✨ Características

- ➕ **Agregar tareas** - Añade nuevas tareas fácilmente
- ✏️ **Editar tareas** - Modifica el texto de tus tareas existentes
- ✅ **Marcar como completadas** - Visualiza tu progreso con checkboxes personalizados
- 🗑️ **Eliminar tareas** - Remueve tareas que ya no necesitas
- 🌙 **Modo oscuro** - Interfaz elegante y amigable para la vista
- 📱 **Diseño responsive** - Funciona perfectamente en móviles, tablets y desktop

## 🛠️ Tecnologías utilizadas

- **React** - Biblioteca principal para la interfaz de usuario
- **Tailwind CSS** - Estilizado rápido y personalizable
- **Vite** - Build tool y entorno de desarrollo

## 🚀 Cómo ejecutar el proyecto

### Prerrequisitos

- Node.js (versión 14 o superior)
- npm o yarn

### Instalación

1. Clona el repositorio

```bash
git clone https://github.com/tu-usuario/To-Do-React-App.git
```

2. Entra al directorio del proyecto

```bash
cd To-Do-React-App
```

3. Instala las dependencias

```bash
npm install
```

4. Ejecuta la aplicación en modo desarrollo

```bash
npm run dev
```

5. Abre http://localhost:5173 en tu navegador
